# Sécurité

Ne publiez jamais de mot de passe Wi-Fi, clé API, token ou cookie de session.

Les opérations de flash/OTA sont protégées par l'interface privée. Les mises à jour distantes doivent utiliser HTTPS, vérification SHA-256 et rollback lorsque la partition OTA le permet.

Pour signaler un problème de sécurité, ouvrez une issue privée ou utilisez les mécanismes de sécurité du dépôt GitHub.
