# ESP-IDF 6.1 dans VS Code\n\nLe projet est prévu pour un environnement ESP-IDF installé dans :\n\n```text\nC:\\esp\\v6.1\\esp-idf\n```\n\n## Terminal\n\nOuvrir un PowerShell et :\n\n```powershell\n. C:\\esp\\v6.1\\esp-idf\\export.ps1\ncd C:\\chemin\\ESP32_LAB_IDF6.1_PRO\\firmware\\master\nidf.py set-target esp32s3\nidf.py build\n```\n\nDans VS Code, ouvrir le dossier `firmware/master` ou le dépôt entier. Le plugin Espressif peut être utilisé pour la navigation, `build`, `flash`, `monitor` et `menuconfig`; les commandes `idf.py` ci-dessus restent la référence reproductible.\n
