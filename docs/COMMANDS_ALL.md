# Commandes ESP32 LAB — ESP-IDF 6.1 + Arduino CLI + GitHub\n\n## 1. Terminal ESP-IDF Windows\n\n```powershell\ncd C:\\esp\\v6.1\\esp-idf\n.\\export.ps1\n\n# Vérifier\nidf.py --version\n```\n\n## 2. Préparer et construire le MASTER\n\n```powershell\ncd C:\\chemin\\ESP32_LAB_IDF6.1_PRO\\firmware\\master\nidf.py set-target esp32s3\nidf.py reconfigure\nidf.py build\n```\n\n## 3. Flasher le MASTER par le port USB CH343\n\n```powershell\nidf.py -p COM7 flash\nidf.py -p COM7 monitor\n```\n\nOu :\n\n```powershell\nidf.py -p COM7 flash monitor\n```\n\nRemplace `COM7` par le port affiché dans le Gestionnaire de périphériques.\n\n## 4. Effacement complet — seulement récupération\n\n```powershell\nidf.py -p COM7 erase-flash\n```\n\nCette commande supprime les données flash ; ne l’utiliser que lorsque nécessaire.\n\n## 5. Menuconfig\n\n```powershell\nidf.py menuconfig\n```\n\nLes paramètres essentiels sont aussi conservés dans `sdkconfig.defaults`.\n\n## 6. Arduino CLI — compiler tous les projets INO\n\nDepuis la racine du dépôt :\n\n```powershell\narduino-cli core update-index\npython scripts/build_ino.py projects\n```\n\nRésultat : `BUILD_OUTPUT/ESP32`, `BUILD_OUTPUT/ESP32S3`, `BUILD_OUTPUT/AVR`.\n\n## 7. Préparer la SD\n\n```powershell\npython scripts/prepare_sd.py --build BUILD_OUTPUT --projects projects --sd SD_READY\n```\n\n## 8. Vérifications\n\n```powershell\npython scripts/verify_project.py\npython scripts/verify_100k.py\npython scripts/range_analyzer.py projects/IMPORTED_35\n```\n\n## 9. Git\n\n```powershell\ngit init\ngit branch -M main\ngit add .\ngit commit -m "ESP32 LAB initial release"\ngit remote add origin https://github.com/<VOTRE_COMPTE>/<VOTRE_REPO>.git\ngit push -u origin main\n```\n\nNe committez jamais `CONFIG/local_secrets.json` ni aucun fichier contenant de vrais secrets.\n
