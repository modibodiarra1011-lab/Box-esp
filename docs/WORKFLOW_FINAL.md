# Workflow final\n\n## MASTER\n\nESP-IDF 6.1 + VS Code, projet `firmware/master`. Le port CH343/USB-UART est utilisé pour le premier flash et le recovery série.\n\n## SD\n\nLa SD reçoit `SD_CARD/*` à la racine. Les firmwares sont classés par cible et chaque artefact de build reçoit son SHA-256.\n\n## Projets INO\n\n```powershell\npython scripts\\build_all.py --projects projects --output BUILD_OUTPUT --sd SD_READY\n```\n\nLes `.bin` ESP32 sont classés dans `FIRMWARE/ESP32` ou `FIRMWARE/ESP32S3`, les `.hex` AVR dans `FIRMWARE/AVR`.\n\n## Release GitHub\n\n```powershell\npython scripts\\make_release.py BUILD_OUTPUT --version 4.2.0 --base-url https://github.com/<COMPTE>/<REPO>/releases/download/v4.2.0 --out release-manifest.json\n```\n\nPublier ensuite les artefacts comme GitHub Release. Le MASTER doit vérifier HTTPS, cible, taille et SHA-256 avant installation.\n
