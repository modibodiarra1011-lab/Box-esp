# Wiring - Blink ESP32

No external component is required. On common ESP32 Dev Module boards the built-in LED is often on GPIO2, but the exact board revision must be checked if no LED activity is visible.

## Test
1. Select the ESP32 Dev Module target.
2. Upload at 115200 baud.
3. Open Serial Monitor.
4. Observe LED ON/OFF messages every 500 ms.
